# Estructura_de_Datos_Funciones_Extra_por_Grupos
En este repositorio se visualizarán las implementaciones de las nuevas funciones de cada grupo de exposición

Grupo 1 
TEMA: Lista doblemente enlazadas
Funcion a imlementar: Agregar una función invertir() a la lista doblemente enlazada, que invierta el orden de los nodos cambiando los punteros.

Grupo 2 
TEMA: Listas Dobles Circulares
Funcion a imlementar: Agregar una funcion obtenerEnPosicion(int pos) que devuelva el dato almacenado en la posicion pos de la lista.

Grupo 3 
TEMA: Pilas
Funcion a imlementar: Agregar una funcion sizePila() que permita devolver el número actual de elementos almacenados en la pila.

Grupo 4 
TEMA: Colas
Funcion a imlementar: Implementar la función contarElementos()

Grupo 5 
TEMA: INFIJAS-POSTFIJAS-PREFIJAS
Funcion a imlementar: [contarOperadores()] que reciba una expresión infija y cuente los operadores aritméticos [(+, -, *, /, ^)].

Grupo 6 
TEMA: Pilas 
Funcion a imlementar: Implementar la funcion para sumar elementos de la pila
